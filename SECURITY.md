# Security Policy

## Supported versions

Security fixes are released for the latest published version of
`veniceai-cli`. Before reporting an issue, check that it affects the latest
release; `venice update --check` shows whether a newer version is available.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, pull
requests or discussions.

Report them privately through GitHub: open the repository's **Security** tab
and click **Report a vulnerability**.

Please include:

- the affected version (`venice --version`), your Node.js version and your
  operating system
- what the vulnerability allows and the steps to reproduce it
- any suggested fix or mitigation

Never include a real API key or other secret in a report.

We aim to acknowledge reports within 5 business days and will keep you
updated while we investigate and fix the issue. Please give us a reasonable
chance to release a fix before disclosing the issue publicly.
